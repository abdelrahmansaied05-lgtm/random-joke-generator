# 😂 مولد النكات العشوائية - Random Joke Generator

تطبيق ويب تفاعلي لتوليد نكات عشوائية من API خارجي مع واجهة جميلة وميزات متقدمة.

## ✨ المميزات

- 🎭 **نكات عشوائية** من API رسمية
- 🏷️ **تصنيفات متعددة**: عام، Knock Knock، برمجة، متنوع
- 💾 **حفظ محلي (Local Storage)**: احفظ النكات والإحصائيات
- 📊 **إحصائيات**: عداد النكات والأنواع المتاحة
- 📱 **تصميم مستجيب**: يعمل على جميع الأجهزة
- 🚀 **مشاركة سريعة**: شارك النكات مع الآخرين
- 📋 **سجل النكات**: احفظ آخر 20 نكتة تم تحميلها
- ⌨️ **اختصار لوحة المفاتيح**: Ctrl + Enter لتحميل نكتة جديدة

## 🎮 طريقة الاستخدام

1. **افتح الملف** `index.html` في المتصفح
2. **اختر نوع النكتة** من القائمة المنسدلة
3. **اضغط على "احصل على نكتة جديدة"** لتحميل نكتة عشوائية
4. **استمتع!** 😂

## 📊 الإحصائيات

- **نكات تم تحميلها**: عدد النكات التي حملتها
- **أنواع متاحة**: عدد تصنيفات النكات المتاحة

## 📝 السجل

- **آخر النكات**: تعرض آخر 5 نكات تم تحميلها
- **الحذف الفردي**: احذف نكتة محددة من السجل
- **مسح الكل**: امسح جميع السجلات

## 🛠️ التقنيات المستخدمة

- **HTML5** - البنية
- **CSS3** - التصميم والرسوميات
- **JavaScript (ES6+)** - الوظائف التفاعلية
- **Fetch API** - استدعاء API الخارجية
- **Local Storage** - حفظ البيانات محليًا
- **Official Joke API** - مصدر النكات

## 🌐 API المستخدمة

**Official Joke API** - API مجانية توفر نكات عشوائية

```
GET https://official-joke-api.appspot.com/random_joke
GET https://official-joke-api.appspot.com/types
GET https://official-joke-api.appspot.com/jokes/{type}/random
```
